# Статья ProStore для WordPress

Готовая статья о сервисе ProStore с SEO и изображениями.

## Содержимое папки

| Файл | Описание |
|------|----------|
| `prostore-article.html` | HTML-контент статьи для вставки в WordPress |
| `SEO.txt` | SEO-настройки для Yoast SEO / Rank Math |
| `images/` | Изображения для статьи (загрузите в Медиатеку WordPress) |

## Изображения

Изображения находятся в папке `images/`:

- **prostore-hero.png** (1200×630) — главное изображение для заголовка и соцсетей
- **prostore-catalog.png** (800×450) — иллюстрация каталога промтов
- **prostore-sharing.png** (800×450) — иллюстрация обмена и публикации

## Инструкция по публикации в WordPress

### 1. Загрузка изображений

1. Перейдите в **Медиатека** → **Добавить**
2. Загрузите все три изображения
3. Запомните или скопируйте URL каждого изображения

### 2. Создание поста

1. **Записи** → **Добавить новую**
2. Вставьте содержимое `prostore-article.html` в редактор (режим **Текст** или блок **Кастомный HTML**)
3. Замените `ВАШ_САЙТ.ru` на URL вашего сайта во всех тегах `<img>`, либо вставьте полные URL изображений из Медиатеки

### 3. SEO-настройки

1. Установите Yoast SEO или Rank Math (если ещё не установлены)
2. Откройте панель SEO под редактором
3. Заполните поля по данным из `SEO.txt`:
   - Заголовок (Title)
   - Meta Description
   - Focus Keyword
   - Изображение для соцсетей (prostore-hero.png)

### 4. Публикация

1. Установите постоянную ссылку (например: `/prostore-obzor/`)
2. Добавьте изображение записи (Featured Image) — используйте prostore-hero.png
3. Опубликуйте пост
